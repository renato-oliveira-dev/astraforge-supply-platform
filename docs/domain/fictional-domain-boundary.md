# Fictional Domain Boundary

AstraForge Supply Platform models a fictional industrial supply network.

## Canonical Fictional Terms

| Concept | AstraForge term |
|---|---|
| Purchase request | Requisition |
| Authorized commercial commitment | Purchase Order |
| Buying entity | Organization |
| Delivery or consumption location | Facility |
| Sellable or stocked reference | Catalog Item |
| Provider | Supplier |
| Internal stock commitment | Inventory Allocation |
| Human or automated authorization | Approval Decision |
| End-of-process financial comparison | Invoice Reconciliation |

## Naming Rule

Examples must use invented organizations, people, identifiers, SKUs, addresses, prices, and messages. Avoid names, status vocabularies, segment codes, or payload shapes associated with a real employer or client.

## Example Organizations

- Forge & Field Maintenance
- Northstar Components Cooperative
- Blue Quarry Facilities
- Cedarline Safety Supply

These names are fictional and exist only to support tests and documentation.
